# Scoring Rules

## Group Stage

Points are awarded per match result for each of a player's drafted teams.

| Outcome | Points |
|---------|--------|
| Win     | 3      |
| Draw    | 1      |
| Loss    | 0      |

## Knockout Stage

Points are awarded for each knockout round win.

| Round           | Points |
|-----------------|--------|
| Round of 32     | 5      |
| Round of 16     | 8      |
| Quarter-final   | 11     |
| Semi-final      | 14     |
| 3rd Place Match | 14     |
| Final (Champion)| 20     |

## Notes

- Points accumulate across all 12 of a player's drafted teams.
- Penalty shootout wins count as wins.
- A team that is eliminated stops contributing points.
- Each game has a defined score outcome — there are no bonus points or multipliers beyond the above.
