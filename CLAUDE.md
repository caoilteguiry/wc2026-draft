# CLAUDE.md

## Project Context

This repository contains a World Cup Draft application.

## Working Style

- **Always discuss before implementing.** When asked a question or given a vague instruction, answer and explain the approach first. Wait for explicit approval ("yes", "go ahead", etc.) before writing any code or making any file changes. Do not treat a question as an instruction to implement.

## Development Principles

1. Simplicity over flexibility.
2. Prefer explicit business logic over generic frameworks.
3. Keep tournament rules deterministic.
4. Optimize for maintainability rather than premature scale.
5. All scoring logic must be testable.
